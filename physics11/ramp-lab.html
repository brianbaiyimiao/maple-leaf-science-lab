Lab: Inclined Plane

Objective

Investigate how mass, angle, length, and friction affect acceleration.

Equations

$F_{gx} = mg \sin\theta$ (Down slope)
$F_{N} = mg \cos\theta$ (Perpendicular)
$F_{f} = \mu F_N$
$F_{net} = F_{gx} - F_f$

Procedure

  1. Set a heavy mass (e.g., 100kg).
  2. Set ramp length to 20m.
  3. Increase angle until box moves.
  4. Use PAUSE to stop and calculate forces.
